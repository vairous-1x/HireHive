# HireHive 🐝

HireHive is a modern, dynamic job portal designed to bridge the gap between talented professionals and forward-thinking enterprises. It streamlines the recruitment process with a sleek interface, advanced matching features, and dedicated dashboards tailored for both job seekers and companies.

## 🚀 Key Features

*   **Dual Dashboards**: Specialized views for Enterprises (to post ads and review applicants) and Job Seekers (to browse jobs and manage their profile).
*   **Intuitive Application Flow**: Easy-to-use application tracking system allowing seamless communication and updates.
*   **Company Advertising**: Enterprises can post visual, animated job advertisements directly on the platform's homepage to attract top talent.
*   **Responsive UI**: Modern, dark-mode ready design built with vanilla CSS, custom cursor animations, and fluid interactions.
*   **Secure Authentication**: Role-based access control and session management to ensure data privacy and secure logins.

## 🛠 Technology Stack

*   **Frontend**: HTML5, Vanilla CSS, Vanilla JavaScript, Bootstrap 5 (for utility styling)
*   **Backend**: PHP (Core)
*   **Database**: MySQL

## ⚙️ Prerequisites & Setup

1.  **Web Server**: Ensure you have a web server like Apache or Nginx running (e.g., XAMPP, WAMP, or MAMP).
2.  **PHP**: PHP 7.4 or higher is recommended.
3.  **Database**: MySQL server running locally or remotely.

### Installation

1.  Clone this repository to your local web server's document root (e.g., `htdocs` for XAMPP).
2.  Start your Apache and MySQL servers.
3.  Ensure your MySQL connection details match those in `db_connect.php`.
4.  Navigate to `http://localhost/HireHive/index.html` in your web browser.
